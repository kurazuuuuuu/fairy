# フロントエンド
## 技術スタック
- **Framework**: Vue 3
- **Build Tool**: Vite
- **Language**: TypeScript

## URL: https://fairy.krz-tech.net

## 機能概要

### ページ構成
- **Home (/)**:
    - サービスのトップページ。
    - Discord Botの招待リンクや使い方の説明が表示されます。
- **Research Result (/:uuid)**:
    - リサーチ結果の詳細表示ページ。
    - AIによる要約、詳細レポート、参考URL一覧が表示されます。
    - 共有用URLとしても機能します。

### 共有
- URL: https://fairy.krz-tech.net/{UUID}
    - 誰でも閲覧可能なリサーチ結果ページです。
